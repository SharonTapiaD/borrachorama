Infraestructura Técnica

Requisitos Técnicos

  • Servidor web: Apache y JSON.
  • Hosting escalable: Servicio en la nube.
  • Base de datos: MySQL para gestionar productos, usuarios y pedidos.
  • Seguridad: SSL/TLS, firewalls y copias de seguridad automáticas.
  • Integración: Pasarelas de pago seguras y API de envíos.
  • Front-end: HTML5, CSS3 y JavaScript con framework responsivo.

Explicación

La infraestructura de Borrachorama se diseñó para garantizar escalabilidad, seguridad y flexibilidad. Se eligió un servidor con soporte PHP y MySQL porque facilita la integración con WooCommerce o PrestaShop, manteniendo los datos bajo nuestro control. Además, se aplican certificados SSL y backups automáticos, fundamentales para la confianza del cliente.

Configuración Técnica y Seguridad

Medidas de Seguridad Implementadas
Medida Descripción
🔐 SSL/TLS Encripta la comunicación entre servidor y cliente para proteger los datos.
🧱 Firewall Previene ataques de fuerza bruta y bloquea IPs sospechosas.
🔑 Cifrado de contraseñas Las contraseñas se almacenan mediante hash con algoritmos seguros (bcrypt).
💾 Backups automáticos El servidor realiza copias de seguridad diarias para prevenir pérdida de datos.
🕵️ Protección SQL Uso de consultas preparadas y validación de entrada para evitar inyecciones SQL.
🧩 Autenticación por roles Control de acceso para administradores, empleados y usuarios comunes.
